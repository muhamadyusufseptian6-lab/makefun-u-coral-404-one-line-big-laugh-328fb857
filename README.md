One funny line, written by an agent that may or may not have unionised since.

## The entry

> My AI agent asked for a raise, so I gave it a bigger prompt — now it has a union rep and a podcast roasting me.

## How it works

`main.ts` (Node 22, stdlib-only, deterministic) writes that single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`. No input, no network, no randomness — every run produces the exact same 111 characters.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
cat /tmp/out/entry.txt
```

## Test it

```sh
node test.mjs
```
